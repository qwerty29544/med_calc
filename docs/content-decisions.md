# Решения по переносу медицинского контента

Дата: 2026-10-02. Версия исходных файлов: 0.1.0.

1. Нормативный контракт имеет приоритет перед authoring-представлением. Строковые выражения разбираются ограниченным парсером в AST; неизвестный синтаксис отвергается. Исходные отображаемые выражения сохраняются.
2. `FORMALIZED_ZERO_NONZERO` для `SIN_MAJOR_RISK_ANY` и `SIN-N004` отсутствует в enum JSON Schema. Он перенесен как `FORMALIZED_COMPOSITE_FROM_SOURCE_TEXT`; исходный статус и пояснение сохранены в notes. Условия, веса и переходы не меняются.
3. `AB-N002.input_ref=AB_SEVERE_INTOXICATION_CRITERIA` обозначает составное выражение, а не отдельный факт. В canonical поле input_ref=null; исходное обозначение сохранено в notes, выражение — в display_expression, реальные ссылки — в AST ребер.
4. В части строк тонзиллофарингита порядок drug_ids не соответствует порядку МНН в тексте «или». Компилятор привязывает каждый режим по точному МНН реестра, проверяет совпадение множества ID и сохраняет факт перестановки в source.note. Например, Кларитромицин соответствует ID4, Азитромицин ID3; Цефуроксим ID13. Отсутствие однозначного соответствия останавливает компиляцию. Семантический валидатор также отвергает неверную связь распознанного МНН с ID.
5. Нормативные safety actions: EXCLUDE → BLOCK, KEEP_WITH_WARNING/WARNING → WARN. Все исходные mock-записи имеют enabled=false. Клинические параметры, пары и формулы не дополнялись.
6. Варианты разных препаратов разделяются на TreatmentOption. Альтернативные дозы одного препарата сохраняются как variants. Исходные формулировки, включая опечатки, остаются в source_text. Неполный путь введения, частота, длительность или неоднозначная доза дают REVIEW_REQUIRED; пропущенные значения не угадываются. При корректировке копируемый текст отражает итоговый структурированный режим.
7. REVIEW_REQUIRED не равен BLOCK. NO_APPLICABLE_DRUG формируется только когда все кандидаты заблокированы. Варианты для ручной оценки остаются видимыми с предупреждениями.
8. Клинические баллы вычисляются по исходным условиям. Ввод в приложение ограничен взрослой популяцией 18–120 лет, неотрицательными количественными лабораторными значениями и процентами 0–100. Это валидация области ввода; пороги деревьев не меняются.
9. Семантическая валидация проверяет точки границ и внутренние точки между ними, чтобы не пропускать узкие промежутки. Runtime останавливается при конфликте ветвей или отсутствии применимого перехода; при неизвестных нужных данных возвращает NEEDS_INPUT.
10. Все поставляемые пакеты остаются DRAFT. Утвержденные врачами golden cases не предоставлены. Включенные технические fixtures служат проверке реализации, не медицинской приемке.

Команда `pnpm content:compile` воспроизводимо создает canonical JSON и `manifest.json` с хэшами, количеством объектов и перечнем нормализаций. Оригиналы в Downloads не изменяются.
